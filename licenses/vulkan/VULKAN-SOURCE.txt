This application bundles the ARM64 runtime libraries from the official LunarG Vulkan SDK 1.4.363.0 (2026-09-29).
The SDK SHA-256 and unmodified input binary hashes are pinned in vulkan-upstream.json.
Only the macOS install names and local ad-hoc code signatures are changed; the universal loader is thinned to ARM64.
No validation, capture, debug layers, SDK compiler tools, or Mesa OpenGL driver are bundled.

Runtime requirements: Apple Silicon, macOS 26+, Metal 4. This is an optional experimental PSP backend. The application's default MoltenVK path remains compatible with macOS 14+.
