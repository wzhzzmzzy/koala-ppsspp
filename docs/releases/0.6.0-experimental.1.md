# Koala PS 0.6.0-experimental.1

PSP 新增可选的 **KosmicKrisp 实验驱动**。默认仍使用 MoltenVK，PS2 保持 ARMSX2 / Metal。

## 使用方式

1. 下载本发布的 `Koala-PSP-0.6.0-experimental.1-macOS-arm64.zip` 并解压完整 App。
2. 打开 `Koala PSP.app`，选择 PSP，然后打开「播放设置 → 视频与画质」。
3. 将图形驱动改为「KosmicKrisp · 实验性」，保存后重新启动游戏。
4. 在「日志与调试」确认实际驱动为 KosmicKrisp。出现兼容性问题时，结束游戏、改回 MoltenVK，再启动。

KosmicKrisp 需要 **M 系列 Mac + macOS 26+**；默认 MoltenVK 路径的最低系统仍为 macOS 14。完整 ZIP 包含引擎、驱动、Vulkan Loader、图标和依赖，无需安装 SDK。游戏库、按键和存档继续共用，两个驱动的缓存分开保存。旧版 0.5.1 ZIP 继续保留。

## 实现与版本

- 原生 SwiftUI/AppKit 设置；选择持久化到 XDG config，仅在下次启动生效。
- MoltenVK 直接加载路径保持原样；KosmicKrisp 通过独立 Vulkan Loader 和随包相对路径 ICD 加载。
- 明确指定驱动失败时正常报错退出，不自动改用 OpenGL/MoltenVK。诊断显示实际返回的驱动、设备及版本，保留上次会话记录。
- PPSSPP 1.20.4，固定源码 `fa50bb1976065c4f8b1b47af227d367fe9771555` 加仓库补丁。
- LunarG Vulkan SDK 1.4.363.0；Loader `fa218055ff4948b159f31d43f800c808a13d51df`；KosmicKrisp/Mesa `269a955c898df283fc36f4827643769068cf3d29`。官方预构建运行库的下载和输入文件 SHA-256 均固定在 `vulkan-upstream.json`。
- 保留远端 README 的 Koala PS 名称与介绍调整。

## 实际验证

环境：M3 Pro / macOS 26.2。所有运行测试使用隐藏窗口或无窗口模式，没有激活应用，也没有测试全屏。

| 检查 | 结果 |
| --- | --- |
| 原生构建、偏好迁移与重读、驱动环境隔离和系统门槛 | 通过 |
| 缺少 KosmicKrisp 文件时启动拦截、回到 MoltenVK | 通过 |
| 强制缺失 ICD，确认错误退出且没有静默回退 | 通过，exit 1 |
| cube 测试程序：真实驱动识别、渲染、截图、暂停/恢复、退出 | 两个后端通过；截图人工查看 |
| 最终 ZIP 移到含空格路径后，重复双驱动测试 | 通过；33 次后台采样均无激活或可见窗口 |
| 全部 41 个原生二进制的 ARM64 / 最低版本 / 依赖、App 及 ZIP 签名 | 通过 |
| ZIP 移位后的 XDG 偏好与 PS2 无窗口配置启动 | 通过 |
| PSP 设置离屏视觉检查、PS2 存储/配置/旧库回归 | 通过 |

**边界：**原来的《战神：奥林匹斯之链》ISO 不在指定路径，本次未重新验证该游戏。没有前台性能对照、长时间游玩、完整兼容性或第二台 Mac 测试。后台呈现频率受到窗口状态影响，不宣称 KosmicKrisp 比 MoltenVK 更快。PS2 仍无 BIOS/游戏实测。

应用为本地 ad-hoc 签名，尚未经过 Apple Developer ID 公证。ROM、BIOS、存档与私人设置不在包内。
